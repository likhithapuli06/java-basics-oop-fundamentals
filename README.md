# Task 1 – Java Basics & OOP Fundamentals

## Overview

This project was developed as part of the Alfido Tech Internship to demonstrate Java basics and Object-Oriented Programming (OOP) concepts.

## Concepts Covered

### Java Basics

* Conditional statements
* For loops
* Arrays
* Calculating total and average

### OOP Concepts

**1. Class and Object**
A `Student` class is created and objects are used to store and display student information.

**2. Encapsulation**
Student properties are declared as `private` and accessed using getters and setters.

**3. Inheritance**
The `GraduateStudent` and `Teacher` classes inherit properties and methods from the `Student` class.

**4. Polymorphism**
The `displayRole()` method is overridden in different classes. The appropriate method is called based on the actual object.

## Technologies Used

* Java
* Object-Oriented Programming
* Java Collections: Not used
* JDK

## How to Run

Compile all Java files:

```bash
javac *.java
```

Run the main program:

```bash
java Main
```

## Expected Output

The program displays:

* Conditional statement result
* Numbers using a loop
* Array total and average
* Student details
* Encapsulation using getters and setters
* Inheritance example
* Polymorphism example
